---
title: "Wallet & Balance"
description: "Retrieve a user's default wallet balance and all available wallet balances."
---

**Base URL:** `https://your-domain.com/api`

<Info>All endpoints on this page require `Authorization: Bearer {token}`.</Info>

---

## GET /get-default-wallet-balance

Returns the formatted balance of the user's default wallet (the wallet marked `is_default = Yes`).

### Request parameters

<ParamField query="user_id" type="number" required>
  The authenticated user's ID.
</ParamField>

### Response fields

<ResponseField name="success" type="object">
  <Expandable title="properties" defaultOpen>
    <ResponseField name="status" type="number">
      `200` on success.
    </ResponseField>
    <ResponseField name="defaultWalletBalance" type="string">
      Formatted balance string including currency symbol and code, e.g. `$1,250.00 USD`.
    </ResponseField>
  </Expandable>
</ResponseField>

### Error responses

| Status | Reason |
|--------|--------|
| `401` | User not found or no default wallet set |

```bash
curl --request GET \
  --url 'https://your-domain.com/api/get-default-wallet-balance?user_id=42' \
  --header 'Authorization: Bearer {token}'
```

---

## GET /available-balance

Returns all wallets belonging to the user, including currency codes and current balances. Use this endpoint to populate wallet selectors across the app.

### Request parameters

<ParamField query="user_id" type="number" required>
  The authenticated user's ID.
</ParamField>

### Response fields

<ResponseField name="success" type="object">
  <Expandable title="properties" defaultOpen>
    <ResponseField name="status" type="number">
      `200` on success.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="wallets" type="array">
  Array of wallet objects. Each item contains:
  <Expandable title="wallet properties">
    <ResponseField name="currency_id" type="number">Currency ID.</ResponseField>
    <ResponseField name="code" type="string">Currency code, e.g. `USD`.</ResponseField>
    <ResponseField name="balance" type="number">Numeric balance.</ResponseField>
    <ResponseField name="is_default" type="string">`Yes` or `No`.</ResponseField>
  </Expandable>
</ResponseField>

### Error responses

| Status | Reason |
|--------|--------|
| `401` | `user_id` parameter missing |

```bash
curl --request GET \
  --url 'https://your-domain.com/api/available-balance?user_id=42' \
  --header 'Authorization: Bearer {token}'
```
